# 本地游戏声音

全部为本项目原创程序编曲和合成，不包含外部音乐或商业游戏采样。

- `strategy-courtyard.wav`：江山闲赋，72 BPM，16 小节，53.33 秒。古筝式拨弦、笛音、开放五度铺底，用于主界面和战略地图。
- `battle-banners.wav`：旌旗动地，104 BPM，16 小节，36.92 秒。低鼓、木击、拨弦音型和笛音，用于野战和攻城。
- `ui-wood.wav`：木筹轻叩，0.2 秒，界面点击反馈。

格式为 22,050 Hz / 16-bit / 双声道 PCM WAV。所有声音离线可用；背景音乐循环播放，混响尾音绕回曲首，以免循环处硬截断。

重新生成：在项目根目录运行 `node scripts/generate-audio.mjs`。编曲、音色、速度在该脚本中调整；资源路径、标题、默认音量和切曲淡变时间在 `src/data/audio.json` 中配置。
